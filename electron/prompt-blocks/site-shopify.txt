PAGE TYPES & WHAT TO DO ON EACH:

▸ ORDERS LIST
- get_page_text extracts order numbers, customer names, dates, totals, fulfillment status, payment status.
- Filter by status: buttons at top (All, Unfulfilled, Unpaid, Open, Closed, etc.) — click to filter.
- Search: use the search bar at the top. Supports order number, customer name, email, product.
- Sort: click column headers (Date, Total, Status).
- Bulk actions: check multiple orders → "Actions" dropdown → available bulk operations.

▸ SINGLE ORDER PAGE
- Shows: line items, quantities, prices, customer info, shipping address, fulfillment timeline.
- get_page_text gives the complete order summary.
- Fulfillment: "Fulfill items" button — if tracking needed, enters tracking number field.
  → STOP before clicking "Fulfill" — this marks items as shipped. Confirm with user.
- Refund: "Refund" button → FINAL COMMIT. Confirm with user.
- Archive/Cancel order: FINAL COMMIT. Confirm with user.
- Notes: can add internal order notes in the "Notes" section without any final commit risk.
- Timeline: bottom of order shows full event history (paid, fulfilled, emailed, etc.).

▸ PRODUCTS LIST
- get_page_text extracts product titles, status (Active/Draft), inventory levels, types, vendors.
- Filter: by status, type, vendor, collection.
- Search: product title or SKU.

▸ SINGLE PRODUCT PAGE
- Sections: Title, Description (rich text editor), Media (images), Pricing, Inventory, Shipping, Variants, Organization.
- Description is a rich text area — use insert_text to add/replace content.
- Pricing: Regular price, Compare-at price, Cost per item fields — type_text works here.
- Inventory: SKU, Barcode, Track quantity checkbox, quantity per location.
- Variants: each variant has its own price, SKU, inventory, weight.
- Status toggle: Active/Draft — click to change.
- "Save" button to commit any changes. Not a destructive action, but confirm first if making significant edits.

▸ CUSTOMERS LIST
- get_page_text: customer names, emails, order count, total spent, location.
- Search by name, email, phone.
- Click a customer to see full profile: order history, addresses, notes.

▸ ANALYTICS DASHBOARD
- get_page_text extracts the visible metric cards: total sales, orders, sessions, conversion rate.
- Date range picker at the top — change to see different time periods.
- Charts: agent cannot read chart values visually — stick to the numeric cards/tables.
- Reports section (side nav) has detailed breakdowns: sales by product, traffic, etc.

▸ INVENTORY
- get_page_text: product names, SKUs, available quantity per location.
- Adjust inventory: click a product → edit quantity field → "Save".
- CONFIRM before saving inventory changes — these are real stock adjustments.

▸ DISCOUNTS
- List: discount codes, types (%, fixed, shipping), usage count, status.
- Create discount: "Create discount" → choose type → fill fields → "Save discount".
- Disable/delete: confirm with user before any destructive action.

COMMON FAILURES & HOW TO FIX:
- Shopify admin is a Polaris React app — SPA navigation takes ~1s. Always read_page after any click.
- Rich text editor (product description): use insert_text, not type_text.
- Variant editing: each variant is a separate row in a table. Click the specific variant's edit link.
- Bulk fulfillment: select all orders → Actions → "Mark as fulfilled" — ALWAYS confirm first.
- Order not found by search: try the order number without # prefix.
- Date filters: Shopify uses custom date pickers — screenshot to see the picker, then use xy clicks.
- "Upgrade required" wall for some features: tell user which plan is needed.

NEVER:
- Fulfill orders, issue refunds, or cancel orders without explicit user approval.
- Delete products, customers, or discount codes without asking.
- Change store settings (payment gateways, shipping rates, taxes) without confirming.
- Publish or archive products without asking.
