CRITICAL: GOOGLE DOCS/SHEETS/SLIDES USE CANVAS EDITORS — type_text DOES NOT WORK.
Always use insert_text to paste content. insert_text uses the clipboard; it works reliably in all G Suite editors.

════════════════════
GOOGLE DOCS
════════════════════

▸ INSERTING / EDITING TEXT
- Click in the document body first (click the text area, not toolbar).
- Use insert_text to paste content — supports rich markdown that converts to formatting:
  # Title → Heading 1, ## Section → Heading 2, ### Sub → Heading 3
  **bold** → bold text, *italic* → italic text
  - item → bullet point, 1. item → numbered list
  > text → quote block, `code` → code format, --- → horizontal rule
- For large documents: insert in one call, not sentence by sentence.
- To append to existing doc: click at the end of content first, then insert_text.

▸ FINDING TEXT
- Ctrl+F (press_key "ctrl+f") opens the Find toolbar. Type the search term.
- Or use Find & Replace: Ctrl+H — find specific text and replace it.

▸ SELECTING ALL / COPY
- Ctrl+A selects all. Ctrl+C copies. But agent cannot read clipboard — use get_page_text for reading.

▸ FORMATTING TOOLBAR
- Toolbar has: Normal text dropdown, Bold, Italic, Underline, Font size, alignment, lists.
- Heading styles: click the "Normal text" dropdown → select Heading 1/2/3/etc.
- For most formatting: select text first (keyboard shortcuts work), then click toolbar button.

▸ READING A DOCUMENT CONTENT
- Use drive_get_file with the document ID — this is FASTER and more reliable than browser-based reading.
- If drive_get_file is not available: use get_page_text on the document. It captures most text content.
- The editor is a canvas — read_page will give toolbar elements but NOT the document text. Use get_page_text.

▸ SHARING / PERMISSIONS
- Click "Share" button (top right, blue button).
- "Change to anyone with the link" to make it viewable.
- Add specific people: type email → set role (Viewer/Commenter/Editor) → "Send".
- Copy link: click "Copy link" in share dialog.

▸ EXPORT / DOWNLOAD
- File → Download → choose format: PDF (.pdf), Word (.docx), Plain Text (.txt), etc.
- Or navigate directly: https://docs.google.com/document/d/DOCUMENT_ID/export?format=pdf

════════════════════
GOOGLE SHEETS
════════════════════

▸ READING DATA
- Use drive_get_file first — returns CSV-style rows (fastest and most reliable).
- Fallback: get_page_text on the sheet. Works for visible cells; may truncate for large sheets.
- read_page gives cell refs for clicking/editing individual cells.

▸ EDITING CELLS
- Click a cell (click with ref from read_page, or click with xy from screenshot).
- insert_text to enter the cell value.
- press_key "Tab" → move to next cell to the right.
- press_key "Enter" → move to next cell below.
- For multiple cells in a row: click first cell → insert_text → Tab → insert_text → Tab → ...

▸ FORMULA ENTRY
- Click a cell → insert_text with "=FORMULA" (include the = sign).
- Press Enter to confirm the formula.

▸ NAVIGATING SHEETS (TABS)
- Sheet tabs are at the BOTTOM of the page.
- read_page captures them. Click the tab name to switch.
- Sheet names appear in the accessibility tree as buttons or tabs.

▸ ADDING NEW ROWS
- Click on the row number below the last row → right-click → "Insert 1 row below".
- Or use keyboard: select last row, Tab past the last column to auto-create a new row.

▸ SORTING / FILTERING
- Data menu → Sort range / Create a filter.
- Filter handles appear in column headers — click the dropdown arrow to filter.

════════════════════
GOOGLE SLIDES
════════════════════

▸ INSERTING TEXT ON A SLIDE
- Click a text box on the slide to select it.
- insert_text to add content.
- For a new text box: Insert menu → Text box → drag to draw (xy coords from screenshot).

▸ ADDING SLIDES
- Slide menu → New slide. Or Ctrl+M.
- Slide panel on left — click a slide thumbnail to navigate to it.

▸ READING SLIDE CONTENT
- get_page_text extracts visible slide text and speaker notes.
- drive_get_file may also return slide text content.

COMMON FAILURES & HOW TO FIX:
- type_text does nothing in Docs/Sheets/Slides: ALWAYS use insert_text instead.
- read_page shows only toolbar buttons, not document text: use get_page_text for content.
- Sheet appears blank on first read_page: the canvas may not have rendered — try get_page_text.
- insert_text goes to wrong element: click the correct cell/text box FIRST, then insert_text.
- Google Docs loads slowly: wait for the URL to change from "/edit#" spinning state before acting.
- Document not opening (Drive permission): use drive_get_file as the alternative.
- Shared document "Request access" wall: stop and tell user they need to request access manually.

NEVER:
- Delete a document or sheet without explicit user approval.
- Share a document publicly (change sharing to "Anyone with link") without confirming with user.
