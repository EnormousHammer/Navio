Keyboard shortcuts

  • Ctrl+T New tab · Ctrl+Shift+N New private tab
  • Ctrl+W Close tab · Ctrl+Shift+T Reopen last closed tab
  • Ctrl+R Reload · Ctrl+Shift+R Hard reload (empty cache)
  • F5 Reload · F12 or Ctrl+Shift+I Page DevTools
  • Alt+← Back · Alt+→ Forward
  • Ctrl+Tab Next tab · Ctrl+Shift+Tab Previous tab
  • Ctrl+PgDn / PgUp Next / previous tab
  • Ctrl+1–8 Jump to tab · Ctrl+9 Last tab
  • Ctrl+L Focus address bar · Ctrl+F Find in page
  • Ctrl+H History · Ctrl+Shift+B Bookmarks · Ctrl+Shift+O Tab search
  • Ctrl+K Command palette · Ctrl+Shift+A AI assistant · Ctrl+Shift+C Connectors

On macOS, use ⌘ in place of Ctrl where shown.
